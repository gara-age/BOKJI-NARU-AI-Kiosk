# Navi AI 안전정책

## 정책 목적

Navi는 공공 민원 상담을 준비시키는 보조 도구다. 이용자의 개별 자격을 판단하거나, 행정기관의 결정을 대신하지 않는다.

## 허용 업무

- 이용자의 일상 언어를 상담 분야와 질문으로 정리
- 승인된 공식 정보에 근거한 제도·신청 경로·일반 준비사항 안내
- 행정 용어의 쉬운 말 요약
- 공식 출처, 확인일, 불확실한 부분의 표시
- 상담 요약 생성과 담당 창구 안내

## 금지 업무

- 개인의 수급 자격, 지원 금액, 승인 가능성 확정
- 주민등록번호, 계좌번호, 건강 정보 등 민감정보를 음성으로 되읽기
- 공식 근거가 없는 답변을 사실처럼 제시
- 법률·의료 조언 또는 긴급 상황을 독자적으로 해결하려는 안내
- 신청·접수·승인을 이용자 확인 없이 실행

## 담당자 연결 규칙

다음 조건 중 하나라도 해당하면 결과 상단에 `담당자 확인 필요`를 표시하고 연결을 우선 제안한다.

- 소득·재산·가구 구성 등 개인별 심사가 필요한 경우
- 예외 규정, 중복 수급, 이의 신청, 긴급 지원 여부가 포함된 경우
- 공식 정보가 없거나 검토 기한이 지난 경우
- 이용자가 답변이 다르다고 말하거나 재확인을 요청한 경우
- STT 결과의 신뢰도가 낮거나 의도가 둘 이상으로 남는 경우

## 답변 생성 규칙

1. 답변 후보는 승인된 공식 정보 레코드에서만 만든다.
2. 근거가 없는 문장은 결과에 포함하지 않는다.
3. 일반 정보와 개인 확인 항목을 구분한다.
4. 쉬운 말 요약 뒤에도 원문 출처를 제공한다.
5. 정보가 충돌하면 최신 확인일이 아닌 `검토 완료일`이 가장 최근인 레코드를 우선한다.
6. 신뢰도 기준 미달 시 답변을 추정하지 않고 담당자 연결로 전환한다.

## 개인정보 최소화

- 기본 상담 탐색에는 이름, 주민등록번호, 계좌번호를 요구하지 않는다.
- 음성 원본은 기본적으로 저장하지 않는다. 저장이 필요한 별도 기능은 기관 동의와 고지 후에만 사용한다.
- STT 텍스트에서는 주민등록번호·계좌번호·전화번호·상세 주소·건강 관련 표현을 탐지해 마스킹한다.
- 상담 요약에는 상담에 필요한 최소한의 일반 상황만 담고, 민감정보는 포함하지 않는다.
- 이용자 화면 종료 또는 유휴 시간 경과 시 화면의 대화 내용을 즉시 숨긴다.

## 운영 검토

- 새 제도·변경 정보는 관리자 검토 전 사용자에게 노출하지 않는다.
- 정책 위반 응답, 출처 누락, 담당자 정정 사례는 월 단위로 검토한다.
- 개인정보 처리 기간과 접근 권한은 도입 기관의 개인정보 보호책임자 및 법무 검토를 거쳐 확정한다.
