# Navi 파일럿 운영 체크리스트

## 시작 전

- [ ] 파일럿 기관, 설치 위치, 운영 기간, 담당 부서를 지정했다.
- [ ] MVP 지원 민원 목록과 기관별 담당 창구를 승인했다.
- [ ] 모든 사용자 노출 정보에 공식 출처와 검토 완료일이 있다.
- [ ] 개인정보 처리 목적, 보관 기간, 접근 권한, 삭제 절차를 기관과 확정했다.
- [ ] 음성 안내가 들리는 환경과 화면 가림 방지 위치를 점검했다.
- [ ] 오류·긴급 상황·민감정보 입력 시 직원 도움 요청 경로를 마련했다.
- [ ] 담당자에게 상담 요약의 범위와 AI의 비판정 원칙을 교육했다.

## 운영 중

- [ ] 매일 STT 실패, 정보 없음, 담당자 연결, 이용자 이탈 사례를 확인한다.
- [ ] 담당자가 정정한 안내와 누락 서류 사례를 기록한다.
- [ ] 근거가 없거나 검토 기한이 지난 정보는 즉시 비노출 처리한다.
- [ ] 화면·인쇄물·QR에 불필요한 개인정보가 포함되지 않는지 점검한다.
- [ ] 사용자 이해도와 완료 여부를 짧은 설문으로 수집한다.

## 종료 후 평가

- [ ] 상담 준비 완료율과 평균 안내 시간을 분석한다.
- [ ] 기존 대비 서류 누락·재방문 사유 변화를 표본 조사한다.
- [ ] 담당자 개입률을 원인별로 분류한다.
- [ ] 의도 분류 오류와 출처 누락을 우선 개선 목록으로 만든다.
- [ ] 다음 파일럿에서 추가할 민원과 제외할 민원을 결정한다.
