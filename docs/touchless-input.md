# 비접촉 손동작 입력

키오스크 화면에서 **비접촉 손동작 사용하기**를 눌러 카메라를 켭니다. 검지로 버튼을 가리키고 엄지와 검지를 붙이면 기존 버튼의 클릭 동작이 한 번 실행됩니다. 다시 손가락을 벌려야 다음 선택이 가능합니다. 방향이 반대이면 **좌우 방향 바꾸기**를 누릅니다. 터치는 언제든 함께 사용할 수 있습니다.

첫 화면의 시점 적응형 UI가 얼굴 추적용 카메라를 자동으로 시작합니다. 비접촉 손동작을 켜면 손 인식기가 **같은 카메라 스트림**을 공유하므로 별도 카메라를 열지 않습니다. 손동작을 끄면 손 인식기만 종료하며, 첫 화면이 열려 있으면 얼굴 추적용 카메라는 계속 동작합니다. 탭이 숨겨지면 얼굴 추적이 중지되고 손동작 입력도 꺼집니다. 영상과 손 좌표는 서버로 보내거나 저장하지 않습니다. MediaPipe 모델과 WebAssembly 파일은 `frontend/public`에서 로컬로 제공합니다.

민감도와 성능 설정은 `frontend/src/touchless/config.ts`에 있습니다. 현재 스냅 반경은 0으로, 실제로 가리킨 허용 버튼만 선택합니다. 카메라와 화면의 위치가 다르면 손 좌표가 실제 터치 위치와 일치하지 않을 수 있으므로 현장 장비에서 좌우 방향과 Pinch 임계값을 확인해야 합니다. 카메라 권한을 사용할 수 없으면 기존 터치·직접 입력을 사용합니다.

커서 안정화는 첫 두 프레임의 위치 일치 확인, 단발성 큰 좌표 오차 보류, 3개 좌표의 중앙값, 이동량에 따른 EMA, 프레임당 최대 이동 제한을 적용합니다. 버튼 선택은 짧은 Hover 유지 후 허용하며, Pinch 중 검지 위치가 조금 움직여도 직전에 가리킨 버튼이 여전히 가까이 있고 가려지지 않았다면 그 버튼을 선택합니다.

가상 커서는 `document.body`의 고정 오버레이에 렌더링합니다. 따라서 키오스크 레이아웃의 확대·변형·스크롤과 무관하게 `elementFromPoint`로 판별한 화면 좌표와 같은 위치에 표시됩니다.

자동 테스트: `cd frontend` 후 `npx playwright test --config=playwright.touchless.config.ts`. 가짜 카메라로 로컬 모델 초기화까지 확인하지만, 실제 손 인식 정확도와 iPad 카메라 설치 각도는 별도 현장 검증이 필요합니다.
